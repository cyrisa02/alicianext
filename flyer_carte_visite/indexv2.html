🛠️ Comment insérer votre logo :

  1. Placez votre fichier logo (ex: logo.png ou logo.svg) dans le même dossier que ce fichier HTML.
  2. Dans le code ci-dessus, cherchez la ligne : src="votre-logo.png"
  3. Remplacez votre-logo.png par le nom exact de votre fichier.
  4. Pour les QR codes, remplacez les blocs <span>QR</span> par une balise <img src="votre-qr.png" class="w-full h-full" />.
  5. Imprimez en PDF (Format A4, marges "Aucune", cocher "Graphiques d'arrière-plan").
  6. Pour personnaliser le QR code, remplacez les div placeholder par de vraies images QR code générées sur un site comme qr-code-generator.com.
